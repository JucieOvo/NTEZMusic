# YAML 曲谱编写文档

本文档详细说明如何为钢琴自动弹奏器编写 YAML 曲谱配置文件。请先阅读本文再开始编写。

---

## 一、文件结构总览

一个完整的 YAML 曲谱文件包含四个顶级区域：

```yaml
song:      # 歌曲元信息：名称、速度、节拍单位
playback:  # 播放参数：启动延迟、按键持续时间
keyboard:  # 键盘映射：简谱音符到电脑键盘按键的映射
score:     # 曲谱事件：音符序列与节拍
```

---

## 二、song — 歌曲元信息

```yaml
song:
  name: "示例曲谱"    # 曲谱名称，仅用于标识和日志输出
  bpm: 120            # 每分钟节拍数，控制整体播放速度
  beat_unit: 4        # 节拍单位，4 表示四分音符为一拍
```

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| `name` | 字符串 | 是 | 歌曲名称，非空，仅用于展示 |
| `bpm` | 浮点数 | 是 | 每分钟节拍数，必须大于 0 |
| `beat_unit` | 整数 | 是 | 节拍单位，必须大于 0，目前主要用于记录和后续扩展 |

---

## 三、playback — 播放参数

```yaml
playback:
  start_delay_seconds: 3    # 启动延迟（秒）
  key_press_seconds: 0.05   # 每次按键按下的持续时间（秒）
```

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| `start_delay_seconds` | 浮点数 | 是 | 开始弹奏前的等待秒数，用于切换窗口，建议 >= 3 |
| `key_press_seconds` | 浮点数 | 是 | 每次按键的按下持续时间，必须大于 0 且小于每个事件的持续时长 |

---

## 四、keyboard — 键盘映射

将简谱音符编号（1-7）映射到电脑键盘按键，分为三个音区。

### 4.1 标准映射配置

```yaml
keyboard:
  high:              # 高音区：+1 到 +7
    "1": "q"
    "2": "w"
    "3": "e"
    "4": "r"
    "5": "t"
    "6": "y"
    "7": "u"
  middle:            # 中音区：1 到 7
    "1": "a"
    "2": "s"
    "3": "d"
    "4": "f"
    "5": "g"
    "6": "h"
    "7": "j"
  low:               # 低音区：-1 到 -7
    "1": "z"
    "2": "x"
    "3": "c"
    "4": "v"
    "5": "b"
    "6": "n"
    "7": "m"
```

### 4.2 布局示意

```
高音区:   q  w  e  r  t  y  u          (do re mi fa so la ti)
中音区:   a  s  d  f  g  h  j          (do re mi fa so la ti)
低音区:   z  x  c  v  b  n  m          (do re mi fa so la ti)
```

### 4.3 音符编号对应关系

| 编号 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|------|---|---|---|---|---|---|---|
| 唱名 | do | re | mi | fa | so | la | ti |
| 简谱 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |

---

## 五、score — 曲谱事件

这是最核心的部分，由一系列事件组成，每个事件包含两个字段：

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| `notes` | 字符串 | 是 | 简谱字符串，空格分隔多个音符 token |
| `beat` | 浮点数 | 是 | 每个 token 占用的拍数，必须大于 0 |

---

## 六、音符标记语法

### 6.1 音区标记

| 标记 | 含义 | 示例 |
|------|------|------|
| `1`-`7` | 中音区 | `5` = 中音 so |
| `+1`-`+7` | 高音区 | `+1` = 高音 do |
| `-1`-`-7` | 低音区 | `-5` = 低音 so |

### 6.2 休止符

| 标记 | 含义 |
|------|------|
| `0` | 休止一拍（不按键，仅等待） |
| `rest` | 同休止符 |

### 6.3 变音记号（升降半音）

支持在单个音符前添加变音记号，实现半音升降。

| 标记 | 含义 | 底层实现 | 示例 |
|------|------|----------|------|
| `#` | 升半音 | 按下 Shift 的同时按下音符键 | `#4` = 升 fa |
| `b` | 降半音 | 按下 Ctrl 的同时按下音符键 | `b3` = 降 mi |
| `B` | 同降半音 | 同 Ctrl + 音符键 | `B7` = 降 ti |
| `♭` | 同降半音 | 同 Ctrl + 音符键 | `♭6` = 降 la |

变音记号可与音区前缀组合使用：

| 组合 | 含义 |
|------|------|
| `+#4` | 高音区升 fa |
| `-b6` | 低音区降 la |
| `+B7` | 高音区降 ti |

### 6.4 和弦标记

使用中括号 `[]` 包裹多个音符表示同时按下：

```
[1 3 5]     -> 同时按下 do mi so（大三和弦）
[2 4 6]     -> 同时按下 re fa la
[-5 1 3]    -> 低音 so + 中音 do mi
[1 2 3 4 5] -> 同时按下五音（五声音阶）
```

和弦内部的每个音符独立使用音区前缀，且和弦作为一个整体 token 占用 `beat` 时长：

```yaml
# 同时按下低音 so + 中音 do mi，持续 2 拍
- notes: "[-5 1 3]"
  beat: 2
```

---

## 七、节拍计算

以 `beat_unit: 4`（四分音符为一拍）为例：

| beat 值 | 含义 |
|---------|------|
| `4` | 全音符（四拍） |
| `2` | 二分音符（两拍） |
| `1` | 四分音符（一拍） |
| `0.5` | 八分音符（半拍） |
| `0.25` | 十六分音符（四分之一拍） |

---

## 八、score 的拆分规则

系统会将 `notes` 字符串按空格拆分为多个 token，**每个 token 独立占用 `beat` 时长**。

```yaml
# 一条 notes 包含 7 个 token，每个持续 1 拍
- notes: "1 1 5 5 6 6 5"
  beat: 1
```

等价于连续播放 7 个四分音符：do do so so la la so。

如果需要不同音符占用不同时长，拆成多行：

```yaml
# so 持续 2 拍，so re 各 1 拍
- notes: "5"
  beat: 2
- notes: "5 4"
  beat: 1
```

## 十、编写规范与建议

### 10.1 休止符使用

每句歌词末尾建议加一个休止事件，让旋律有呼吸感：

```yaml
- notes: "1 1 5 5 6 6 5"
  beat: 1
- notes: "0"         # 句末休止一拍
  beat: 1
```

### 10.2 和弦与单音混合

和弦 `[1 3 5]` 作为一个 token 整体占用 `beat`，其内部音符同时按下。可与单音交替使用模拟双手演奏：

```yaml
# 左手低音 + 右手旋律交替
- notes: "[-5 1]"
  beat: 0.5
- notes: "3"
  beat: 0.5
- notes: "[-5 2]"
  beat: 0.5
- notes: "4"
  beat: 0.5
```

### 10.3 节拍精度注意事项

- 节拍精度受系统调度、游戏帧率和输入延迟影响
- 不建议在 `beat: 0.125`（三十二分音符）及更短的节拍下期望高精度
- 高 BPM（>= 160）时建议将 `key_press_seconds` 调低至 0.03-0.04

### 10.4 音区跨度

- `-5`（低音 so）到 `+1`（高音 do）跨度约一个半八度
- 单条旋律不建议超过此范围，否则弹奏手感跨度较大

### 10.5 启动延迟

`start_delay_seconds` 建议至少 3 秒，以便启动后切换到游戏窗口。

### 10.6 文件命名

曲谱 YAML 文件统一存放在项目 `config/` 目录下，文件名使用英文小写加下划线：

```
config/
  example_song.yaml
  a_cruel_angels_thesis.yaml
  test_twinkle_star.yaml
```

## 十一、常见错误排查

| 错误场景 | 原因 | 解决方法 |
|----------|------|----------|
| 弹奏无声 | 窗口未处于前台 | 确保游戏窗口在倒计时结束时处于激活状态 |
| 按键错位 | keyboard 映射配置错误 | 检查音符编号到键盘按键的映射是否正确 |
| 节奏过快 | BPM 过高或 beat 值偏小 | 降低 BPM 或增大 beat 值 |
| 和弦不响 | 和弦内的音符超出音区映射范围 | 检查和弦中每个音符的音区前缀是否正确 |
| 升/降半音无效 | 游戏可能不支持同时按下 Ctrl/Shift 加音符键 | 确认游戏钢琴界面是否支持组合键 |
| 按键卡住 | 程序意外中断导致修饰键未释放 | 手动按下并释放 Ctrl 和 Shift 键复位 |

## 十二、与旧版本的差异

当前版本相比早期版本新增的支持：

| 特性 | 旧版 | 当前版 |
|------|------|--------|
| 升半音 `#` | 不支持 | 支持，使用 Shift+音符键 |
| 降半音 `b` / `B` / `♭` | 不支持 | 支持，使用 Ctrl+音符键 |
| 高音区升降半音 `+#4` | 不支持 | 支持 |
| 和弦内变音 `[#1 3 5]` | 不支持 | 支持 |
| score 校验 | 无 | 严格的类型与完整性校验 |
| keyboard 映射 | 固定三音区 | 支持任意数量音区，自动校验 |
