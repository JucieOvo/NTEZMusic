# UpAgain 曲谱离线转换与 Python 3.12 适配方案

## 1. 目标
解决当前执行环境 Python 版本指向 2.7 导致的各种兼容性问题确保后续以 Python 3.12 运行。同时，由于原版曲谱包含大量 UpAgain 不支持的音符（如低音、升降号半音等），编写离线转换脚本生成严格合规的专用版曲谱，以符合主规则的“禁止在运行时进行降级和数据伪造”要求。

## 2. 意图
1. **Python 3.12 适配**：之前的 Bash 环境默认 `python` 命令指向了 2.7，导致报错。之后我们必须通过 `py -3.12`、`python3` 或绝对路径明确调度 Python 3.12 解释器。 
2. **曲谱合规转换**：NTEZMusic 的原版 YAML（如 `latest_cruel_angel_thesis.yaml`）中包含了底层 `z, x, c` 等键位对应的低音（`-1`等）以及带 `#` 的半音。因为系统规则严格要求**“禁止降级与回退，出错应直接退出”**，所以播放程序碰到不认识的音直接崩溃是正确行为。我们需要用“类似 NTE 的离线数据流”方式，前置新建一个转换脚本清洗原谱，生成合法的 UpAgain 专属 YAML。

## 3. 技术要点
- **创建独立转换模块**：在 `F:\NTEZMusic\UpAgain` 下创建 `upagain_yaml_converter.py`。
- **强制剔除过滤策略 (Strict Filtering)**：
  因为不能进行音符的虚假降级（如把 `#1` 降级读取为 `1`），故采取直接剔除策略：
  1. 剔除所有包含 `#` 或 `b` 的半音标志。
  2. 剔除所有不在 `{"1"~"7", "+1"~"+7", "++1"}` 集合内的跨域音符（如 `-1` 到 `-7` 等低音）。
  3. 若一个和弦因剔除所有不合法音符而变为空，则将其原地替换为休止符 `0`；若仅剩单音，则退化为单音。
- **保留高音策略**：利用我们在 `upagain_auto_player.py` 中写好的 `_pitch_weights` 比对机制，同时也可以在转换时就把和弦直接精简至支持的最高单音，减小运行时的校验负担。
- **输出落盘**：将合规的曲谱数据生成 `upagain_cruel_angel_thesis.yaml` 至 `config` 文件夹。

## 4. 模块划分与数据流
- **Parser 模块**：读取现有 YAML 配置的 `score` 列表部分，逐行拆分 `raw_notes`。
- **Filter 模块**：遍历解析出的音符列表，执行“查表过滤”以及“求最高权重音”。
- **Dumper 模块**：生成不带任何黑键与低音的 YAML 文件。

## 5. 风险点
受限于硬性发声机制，剔除原曲中的和弦伴奏与超出音域的音符后，转换出的谱面表现力会显著比原版 NTE 单薄。

## 6. 执行顺序
1. **获取审批**。
2. **第一步**：在 `UpAgain` 中编写 `upagain_yaml_converter.py`，代码符合详尽的中文注释与三段式变量说明要求。
3. **第二步**：寻找可用的 Python 3.12 解释器命令，并执行转换脚本生成 `config/upagain_cruel_angel_thesis.yaml`。
4. **第三步**：使用 Python 3.12 解释器，驱动 `upagain_auto_player.py` 加载新曲谱进行最终播放测试。
