
# NTEZMusic --- 自适应八度压缩与交叉注意力精排算法

> 作者：JucieOvo
> 创建日期：2026-04-28
> 修改日期：2026-07-11
> 版本：attention_weighted（5 曲基准排名 #2，综合得分 0.5305，仅次于 adaptive_octave_fold 的 0.5310）

---

## 一、问题定义

将完整钢琴曲（88 键 A0-C8，约 7.25 八度）自适应缩编到游戏 3 八度 36 键键盘（C3-B5，MIDI 48-83）。

**硬约束**：36 键固定，无延音踏板，无力度输出，同一时刻最多 4 键同按，Ctrl/Shift 修饰键互斥。

**目标**：在硬约束内最大化听感保真度——保持和声色彩、旋律辨识度、声部流畅性。

---

## 二、全管线架构

```
音频(MP3/FLAC) → Demucs分轨 → piano.wav → 钢琴转录 → MIDI → BPM检测写入 → 压缩 → YAML → SendInput弹奏
                                                                        ↑
                                                              attention_weighted 模式
```

### 2.1 前端：音频 → MIDI

| 阶段 | 工具 | 输出 |
|------|------|------|
| Demucs 分轨 | htdemucs_6s (Hybrid Transformer Demucs) | 6 轨 WAV（piano/bass/drums/guitar/vocals/other） |
| 钢琴转录 | transkun (Neural Semi-CRF Transformer V2) | MIDI（含音高、力度、踏板 CC64） |
| BPM 写入 | librosa onset 包络 + 动态编程 | MIDI tempo 轨道（覆盖默认 120） |

### 2.2 后端：MIDI → YAML

MIDI 音符经量化分组后进入压缩管线，输出 NTEZMusic YAML 简谱。

## 三、数据模型

### 3.1 Token 化

将 MIDI 音高映射为 89 个 token：

| Token ID | 含义 |
|----------|------|
| 0 | 休止符（当前时间片无音符） |
| 1-88 | MIDI 音高 21-108（A0-C8，标准钢琴 88 键） |

### 3.2 时间片量化

按 `quantize_beat`（默认 0.25 拍 = 十六分音符精度）将 MIDI `start_beat` 量化为整型网格索引。同一索引内的音符构成一个和弦。

### 3.3 YAML Token 输出

压缩后的音高按三行键盘映射为简谱 token：

```
+1 #1 +2 b3 +3 +4 #4 +5 #5 +6 b7 +7    (QWERTY 行, C5-B5)
 1 #1  2 b3  3  4 #4  5 #5  6 b7  7    (ASDFGHJ 行, C4-B4)
-1 #1 -2 b3 -3 -4 #4 -5 #5 -6 b7 -7    (ZXCVBN 行, C3-B3)
```

前缀规则：`+` = 高音区（C5-B5），无前缀 = 中音区（C4-B4），`-` = 低音区（C3-B3）。`#` = 升半音（Ctrl），`b` = 降半音（Shift）。

## 四、attention_weighted 算法核心

### 4.1 总览

```
阶段 0: MIDI 量化分组 → {时间片: [原始音高]}
  ↓
阶段 1: 全局趋势线提取 → global_ref[t]（非因果双向指数平滑）
  ↓
阶段 2: 小节切分 → 每 4 拍 = 1 小节 = 16 个时间片
  ↓
阶段 3: 逐小节滑动窗口分割线 → 4 小节窗口，三重交叉验证
  ↓
阶段 4: 逐时间片处理
  ├─ 左右手分离（按分割线）
  ├─ 八度折叠到 C3-B5（统一 k，音程精确保留）
  ├─ 左手简化：交叉注意力综合评分选择
  └─ 最终密度控制：交叉注意力综合评分选择
  ↓
阶段 5: Token 输出 + 去重
  ↓
阶段 6: 精排管线：参数扫描 → 候选生成 → 全局质量分 → 最优选择
```

### 4.2 阶段 1：全局趋势线

**目的**：为八度折叠提供长程参考中心，保证跨乐段听感一致。

**步骤**：
1. 粗粒度窗口采样：4 拍窗口滑动，每窗口取音高中位数（抗异常值）
2. 非因果双向指数平滑（α=0.05）：前向 + 后向消除相位滞后
3. 线性插值回每个时间片粒度

### 4.3 阶段 2：小节切分

**目的**：用音乐结构边界替代纯信号间隙作为分段依据。

4/4 拍号下 1 小节 = 4 拍 = `int(4.0 / quantize_beat)` 个时间片（默认 16）。全曲约 150 小节（等长），替代原休止符间隙分割（不等长 20-30 段）。

### 4.4 阶段 3：滑动窗口分割线

**目的**：为每个小节计算左右手分界线（MIDI 音高阈值），≥ 分为右手，< 分为左手。

**窗口**：当前小节 ± 2 小节 = 5 小节（80 时间片，~7.6 秒）。

**三重交叉验证**：

| 验证 | 方法 | 条件 |
|------|------|------|
| 1. 双峰检测 | 窗口内音高直方图平滑 → 找最低峰与最高峰 → 取谷底 | 跨度 ≥ 12 半音 且 双峰间距 ≥ 8 半音 |
| 2. 运动模式 | 相邻拍最高音级进（≤2 半音）集中于上方；最低音跳进（5-7 半音）集中于下方 | 两比率均 ≥ 50% |
| 3. Velocity | 高力度（≥ 中位数）集中于上方；低力度（< 中位数）集中于下方 | 两比率均 ≥ 50% |

**终裁**：双验证均通过 → 采纳；任一失败 → 退化为段内中位数；兜底 MIDI 60。

分割线**仅用于决定"该简化谁"**——简化后不做音区分区，所有音符统一折叠到 C3-B5。


### 4.5 阶段 4a：自适应八度折叠

**核心原则**：和弦内统一八度偏移 k，保证音程绝对不变。

对时间片的音符合集 `{p₁, …, pₙ}`：

```
1. 遍历 k ∈ [-6, 6]，筛选满足 ∀p: 48 ≤ p + 12k ≤ 83 的 k
2. 选择使映射后平均音高最接近 ref_pitch 的 k
3. 若无统一 k（和弦跨度 > 36），各自独立映射到最接近 ref_pitch 的位置
4. ref_pitch = 0.8 × ref_pitch + 0.2 × avg(mapped)
```

### 4.6 阶段 4b：交叉注意力评分

**位置编码**：正弦编码，以拍点值替代 token index。
```
PE(beat, 2i) = sin(beat / 10000^(2i/D)),  PE(beat, 2i+1) = cos(beat / 10000^(2i/D))
```
D=32 维，多频率分量自动形成多尺度时间视野。时间邻近度 = PE 内积 / D 归一化。

**全局交叉注意力**（衡量音符在全曲中的信息保存支持度）：
```
GlobalAttention(p, t) = Σ_{t'} temporal_prox(t, t')
    × Σ_q pitch_similarity(p, q) × density_weight(|notes[t']|) × duration_weight(dur(q))
```

**段内交叉注意力**（衡量音符在当前乐段的和声功能重要性）：
```
SegmentAttention(p, t, seg) = 同上 + 和声上下文权重 harmonic_context(p, chord_notes[t'])
```

**综合评分**（四维线性加权）：
```
Score = 0.30 × ChordFunction + 0.25 × GlobalAttention + 0.25 × SegmentAttention + 0.20 × VoiceLeading
```

**和声功能优先级**（基于音程距离）：
| 角色 | 音程（半音） | 基础分 |
|------|-------------|:---:|
| 根音/最低音 | 0 | 1.00 |
| 三度音 | 3-4 | 0.85 |
| 七度音 | 10-11 | 0.75 |
| 纯四/增四 | 5-6 | 0.60 |
| 小六/大六 | 8-9 | 0.55 |
| 纯五度 | 7 | 0.45 |
| 小二/大二 | 1-2 | 0.30 |
| 八度重复 | 12n | 0.10 |

Velocity 加权：高力度音符向上修正 `+ velocity/127 × 0.15`，交叉手场景下保护左手旋律。

**声部进行平滑度**：与前后时间片已选音符的最小声部跳变，级进（≤ 2 半音）得高分。

### 4.7 阶段 5：Token 输出与去重

- 同一时间片内同 token 去重（键位唯一性）
- 和弦音符按音高升序排列
- 空白时间片插入休止符 `"0"`
- 休止符 beat = 跳跃时间片数 × quantize_beat


### 4.8 阶段 6：精排管线

**候选生成**：扫描 3 个关键参数 × 3 个取值 = 27 个组合：
- `left_max_chord_notes` ∈ {2, 3, 4}
- `ref_smoothing` ∈ {0.1, 0.2, 0.3}
- `global_trend_alpha` ∈ {0.03, 0.05, 0.08}

裁剪到 12 个最合理的组合，每个生成一个完整候选曲谱。

**候选评分**（四维全局质量分）：
```
GlobalScore = 0.30 × MelodicPreservation   # 旋律保持度（最高音轨迹 DTW）
            + 0.30 × HarmonicCompleteness  # 和声完整度（保留比例，低音加权）
            + 0.20 × DensityBalance        # 密度平衡度（方差倒数）
            + 0.20 × VoiceLeadingQuality   # 声部进行质量（相邻跳变）
```

选择得分最高的候选作为最终输出。

## 五、piano_auto_player 核心机制

### 5.1 修饰键冲突处理

Ctrl（升半音）和 Shift（降半音）不能同时生效（后按入顶掉先前的）。当同一和弦包含 `#` 和 `b` token：

```
t=0:     按下 Ctrl → 按下升半音组键 + 安全自然键
t=1ms:   释放 Ctrl 组 → 释放 Ctrl → 按下 Shift → 按下降半音组键 + 安全自然键
t=hold:  释放全部
```

1ms 切换间隔远低于人耳听觉融合阈值（~50ms），听感等同于同时发声。

### 5.2 节奏调度

```python
seconds_per_beat = 60.0 / bpm
for event in events:
    key_press_time + sleep(event.beat * seconds_per_beat - elapsed)
```

使用 `time.perf_counter()` 自校正，避免系统时钟调整导致的累积漂移。

## 八、已知局限

1. **无延音踏板**：所有音符按量化拍长截断，RMS 能量与原始差异大（相关系数 -0.14）——平台硬约束
2. **3 八度硬上限**：88 → 36 键物理压缩，频谱质心偏移（相关系数 0.13）——不可绕过
3. **小节分割依赖 4/4 拍号**：非 4/4 曲目需调整 `_compute_bar_windows` 或回退到休止符分割
4. **分割线为段级静态阈值**：交叉手场景需依赖 velocity 加权补偿，不能逐时间片动态调角色
5. **无调性检测**：不区分调内/调外音，所有音高平等处理
