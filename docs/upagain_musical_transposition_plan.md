# UpAgain 乐谱核心算法重构：全局最优移调与大调化方案

## 1. 痛点分析与目标
之前的曲谱听感“太垃圾”的根本原因并不是漏音，而是**调式（Tonality）被粉碎**所引发的严重失真。
《残酷天使的行动纲领》（原曲为 C小调 / Eb大调）包含了极多的降号（b3, b6, b7）。我们上一版采用的“就近白键吸附”策略，直接把 `Eb(降Mi)` 吸附成了 `E(Mi)`。这相当于强行把原本悲怆有力的“小调”旋律每一个变音都掰成了“大调”的阳光色彩，导致旋律完全走调、听起来四不像。

结合 UpAgain 这个仅有 15 个纯自然白键的乐器，**唯一在音乐理论上正确的解决方式是：全局移调（Transposition）。**

## 2. 意图与技术重构
我们将重构 `UpAgainSmartScoreConverter`，引入针对玩具钢琴/15键白键键盘最经典的音乐工程算法：

- **第一步：主调侦测与最佳全局移调 (Global Auto-Transposition)**
  读取全曲所有音符后，算法将模拟遍历 `-5` 到 `+6` 共 12 种半音移调方案。
  算出哪一种移调方案能让整首歌里的“黑键”（升降号）数量降到最低甚至为 0（将原曲整体完美搬运至 C大调 或 A小调）。然后把选出的最优移调偏差值作用于所有音符上。

- **第二步：重心八度居中 (Octave Centering)**
  之前的“八度折叠”是碰到超范围的音就单独将其 `-12`，这会导致一段连贯的往上爬的音阶中间突然掉下来，形成“锯齿状”的断层。
  新算法会在全局移调后，计算全曲音高的**平均重心**，然后将全曲统一步进移动 `±12` 的倍数，使得整段主旋律**完整、不被破坏地**平铺包裹在 `60~84` 物理音域内，不发生内部断裂。

- **第三步：平滑的主旋律提取 (Smooth Melody Extraction)**
  在处理和弦剥离时，除了提取最高音，同时撤销上一版极其破坏节奏听感的“短促音静音”逻辑。短促音不该直接消失，这会导致旋律漏风顿挫，我们将原汁原味地保留它们的时长并在新调式下播放。

## 3. 数据流设计
1. **收集阶段**：读取 YAML 中每个 token，解析出真实的绝对 MIDI 数组。
2. **上帝分析阶段**：通过遍历 12 个半音差，找到 `min(black_key_cost)` 的 `delta_key`。
3. **重心调整阶段**：计算 `delta_octave`，使得曲谱均值最贴近 MIDI 的 72 （即 `+1` 这个中央区的键）。
4. **施加与重写阶段**：应用综合 `delta`，将偏移后的自然白键转回 UpAgain 表记（如 `+3`）并产出新的 YAML。

## 4. 风险点
经过全局移调后，生成的《残酷天使的行动纲领》将不再是原曲的绝对音调高度，而是被转换成了在白键上弹奏最优美的 C大调/A小调 版本。这在音乐理论上必定改变了原始定调色彩，但在无黑键限制下是唯一的解法。
