# 《异环》钢琴自动弹奏脚本方案

## 目标

本方案用于实现一个基于 YAML 曲谱配置的自动弹奏脚本。用户在 YAML 中编写简谱、节拍和执行参数，程序读取配置后，将简谱转换为游戏钢琴界面的真实键盘输入。

## 键位映射

根据当前游戏界面，钢琴键位分为三个音区：

| 音区 | 简谱 | 键盘 |
| --- | --- | --- |
| 高音 | 1 2 3 4 5 6 7 | Q W E R T Y U |
| 中音 | 1 2 3 4 5 6 7 | A S D F G H J |
| 低音 | 1 2 3 4 5 6 7 | Z X C V B N M |

简谱规则：

| 写法 | 含义 |
| --- | --- |
| `1` 到 `7` | 中音 |
| `+1` 到 `+7` | 高音 |
| `-1` 到 `-7` | 低音 |
| `0` 或 `rest` | 休止符 |
| `[1 3 5]` | 和弦，同时按下多个键 |

## YAML 结构

YAML 分为四个主要区域：

| 区域 | 职责 |
| --- | --- |
| `song` | 描述曲名、BPM 和节拍单位 |
| `playback` | 描述启动延迟、按键持续时间等执行参数 |
| `keyboard` | 描述简谱到键盘按键的映射 |
| `score` | 描述曲谱事件列表 |

## 数据流

程序执行流程如下：

1. 从命令行参数读取 YAML 路径。
2. 加载 YAML 文件并执行结构校验。
3. 读取 `keyboard` 映射，建立音符到键盘按键的转换规则。
4. 逐条读取 `score`，解析单音、和弦与休止符。
5. 根据 `song.bpm` 和每条事件的 `beat` 计算事件持续时间。
6. 等待启动倒计时，方便用户切换到游戏窗口。
7. 使用真实键盘模拟库向前台窗口发送按键。
8. 曲谱执行完毕后退出。

## 扩展性设计

为便于后续扩展，脚本内部按职责划分为以下组件：

| 组件 | 说明 |
| --- | --- |
| `SongConfig` | 保存曲谱的整体配置 |
| `PlaybackConfig` | 保存播放参数 |
| `ScoreEvent` | 保存单个曲谱事件 |
| `PianoConfigLoader` | 负责读取与校验 YAML |
| `NotationParser` | 负责解析简谱 token |
| `KeyboardInputBackend` | 负责真实键盘输入 |
| `PianoAutoPlayer` | 负责调度播放流程 |

后续如果需要扩展，可以优先从以下方向增加能力：

| 扩展方向 | 建议方式 |
| --- | --- |
| 支持升降音 | 在 `NotationParser` 中扩展 token 语法 |
| 支持更多音区 | 扩展 YAML 的 `keyboard` 区域 |
| 支持不同游戏键位 | 只调整 YAML，不改代码 |
| 支持更多输入方式 | 新增输入后端类，不修改曲谱解析逻辑 |
| 支持小节、重复段 | 在 `PianoConfigLoader` 中增加预处理层 |

## 风险点

1. 游戏窗口必须处于前台，否则键盘输入会发送到错误窗口。
2. Windows 下 `keyboard` 库可能需要管理员权限。
3. 节拍精度受系统调度、游戏帧率和输入延迟影响。
4. 本脚本只使用真实本机键盘输入，不包含窗口注入或绕过机制。
