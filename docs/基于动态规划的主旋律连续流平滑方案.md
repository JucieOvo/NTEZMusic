# 基于动态规划的主旋律连续流平滑方案

## 1. 目标与意图
目前的右手主旋律提取采用单帧局部和弦贪婪计算（取最高音高），在面对复杂的演奏习惯（如琵琶音/琶音 arpeggio、右手带低音伴奏）或转录产生的高频孤立噪点时，可能会在相邻拍子间产生突兀的音高向上或向下跳跃（简称“跳切”）。

本方案的目标是引入**动态规划（Viterbi 算法）**。通过综合评估音高的“显著程度”（音高与音量）和相邻音符在时间轴上的“声部连接平滑度”（音高转移惩罚与随时间的衰减），保证提取出的主旋律为一条连续、平滑且不易跳动的音频控制流，从而使弹奏逻辑更符合真人演奏习惯。

---

## 2. 算法数学设计

我们对时间轴上升序排列的右手和弦组（Onset Groups）运行 Viterbi 算法。

对于第 $t$ 个和弦组中的第 $i$ 个音符 $n_{t,i}$，我们定义其**状态分数 $dp[t][i]$** 代表以该音符结束的全局最佳路径得分。

### 2.1 局部发射状态分数（Emission Score）
音符本身的显著度决定了其作为旋律的静态概率。包含两个部分：
1. **高音偏好（Pitch Preference）**：旋律倾向于高声部。
   $$S_{\text{pitch}}(n) = n.pitch$$
2. **力度偏好（Velocity Preference）**：旋律往往具有较大的击键力度。
   $$S_{\text{vel}}(n) = w_{\text{vel}} \times n.velocity$$
   *其中 $w_{\text{vel}} = 0.1$。例如，力度为 80 贡献 8 分。*

### 2.2 转移状态分数与时域衰减（Transition Score & Temporal Decay）
从前一时间组 $t-1$ 的音符 $u$ 转移到当前组 $t$ 的音符 $v$ 时，音高的跳变（跳切）将面临惩罚。
1. **音高跳变惩罚**：惩罚值与音高差的绝对值成正比。
   $$P_{\text{jump}}(u, v) = w_{\text{trans}} \times |u.pitch - v.pitch|$$
   *其中 $w_{\text{trans}} = 1.5$。*
2. **时域平滑衰减**：如果两个和弦组在时间上相隔较远（例如大休止符后），声部连接的连续性自然减弱。引入指数衰减因子：
   $$\text{Decay}(dt) = e^{-dt / \tau}$$
   *其中 $dt = v.start - u.start$，$dt$ 的物理单位为秒，时间衰减常数 $\tau = 1.0$ 秒。*
3. **综合转移分数**：
   $$S_{\text{trans}}(u, v) = - P_{\text{jump}}(u, v) \times \text{Decay}(dt)$$

### 2.3 动态规划递推关系式
对于 $t > 0$：
$$dp[t][i] = S_{\text{pitch}}(n_{t,i}) + S_{\text{vel}}(n_{t,i}) + \max_{j} \left( dp[t-1][j] - w_{\text{trans}} \cdot e^{-(n_{t,i}.start - n_{t-1,j}.start)/\tau} \cdot |n_{t-1,j}.pitch - n_{t,i}.pitch| \right)$$

在所有组计算完毕后，回溯（Backtrack）找出全局得分最高的一条路径，作为最终提纯的主旋律单音流。
