# 视觉模型左右手标注优化方案

## 1. 目标与意图
原项目在左右手切分和标注上的准确性不足。本方案旨在引入视觉模型，通过分析钢琴弹奏视频，对视频中的左右手关键点与键盘进行追踪，结合时间戳将弹奏点精确分配给左手或右手，最终融合生成包含准确左右手信息的琴谱。视觉方案将极大弥补纯音频切分中面临的声学重叠与指法分配难题。

## 2. 技术要点
1. **键盘区域识别与对齐**：通过边缘检测或语义分割定位钢琴键盘区域，并建立图像坐标到物理琴键（音高）的映射矩阵。可以引入透视变换校准不同录制角度。
2. **手部关键点检测**：接入视觉手势识别模型（如 MediaPipe Hands 或定制化 YOLO 关键点模型），提取左右手共性特征，精准输出各指尖在每一帧的二维坐标。
3. **触键动作与左右手归属匹配**：
   - 提取指尖坐标与琴键区域坐标的物理交集，判定按压动作。
   - 通过追踪手掌及小臂轮廓，清晰界定当前触键点属于左手还是右手。
4. **多模态对齐（视觉与音频/MIDI融合）**：原项目若已有基于音频提取的音高与时间流（Onset/Offset），可通过时间戳将高精度的音频音符与视觉侧捕获的“左右手触键事件”进行硬量化对齐，完成最后的分配纠错。

## 3. 模块划分
- **视频预处理模块**：负责视频的分帧、去噪、音画时间轴提取，以及弹奏初始帧的视角矫正。
- **琴键映射模块**：计算和标定 88 个琴键的具体边界及对应音高，建立视觉坐标系。
- **手势追踪与分配模块**：在连续帧中对左手、右手及其指尖进行目标检测追踪，输出“时间戳-坐标-归属”数据结构。
- **音画融合算法模块**：基于容差窗口寻找与音频 Onset 事件最匹配的视觉触键事件，为每一个音符打上 L(左) 或 R(右) 标记。
- **琴谱生成模块**：承接验证后的结构化带标签标记数据，导出目标曲谱文件（如 MIDI、MusicXML 等）。

## 4. 数据流
1. **输入阶段**：原始弹奏视频输入系统，分离出纯视频轨道与纯音频轨道。
2. **处理阶段**：
   - 纯音频 -> 音频转录引擎 -> 获取精确的音符时间序列 (音高、Onset、Offset、力度)。
   - 纯视频 -> 视频预处理 -> 键盘区域标定与手部关键点坐标序列 -> 获取视觉触键事件序列 (时间、大致音符区块、左右手归属)。
3. **融合阶段**：音符时间序列 + 视觉触键事件序列 -> 对齐与匹配算法 -> 完善的左右手归属映射表。
4. **输出阶段**：映射表 -> 琴谱导出引擎 -> 最终琴谱产物。

## 5. 风险点
1. **视觉遮挡**：在复杂的双手交叉弹奏或视角受限时，极易发生手指重叠及指尖遮挡，导致坐标闪烁或跟丢。需要结合手部追踪的时序上下文和手腕基准点进行推测补全。
2. **音画同步误差**：录制设备的音画不同步会导致帧级对齐产生偏差，需要设计弹性滑动窗口或手动同步校准环节。
3. **性能与算力约束**：高帧率视频逐帧推理手部关键点对算力消耗大，对于工程化落地，需要设计降采样或关键帧重计算机制。

## 6. 执行顺序
1. 搜集并建立小规模参考数据样本（涵盖多种拍摄视角和交叉指法的视频与标准MIDI谱）。
2. 在 `docs` 目录进一步细化手写关键点模型技术选型及评估工作。
3. 开发**视频预处理模块**和**琴键映射模块**的原型脚本。
4. 开发**手势追踪与分配模块**，集成视觉识别并输出左右手坐标，检验追踪准确率。
5. 设计**音画融合算法模块**并进行参数调优。
6. 打通全链路自动化，整合**琴谱生成模块**，替换或优化原项目中现有的切分类。
